**המטרה:** לסדר את צמתי הגרף המכוון בשורה כך ש**כל קשת `(u → v)` פונה קדימה** (`u` מופיע לפני `v`).

- קיים **אם ורק אם הגרף הוא DAG** — גרף מכוון ניתן למיון טופולוגי ⟺ אין בו מעגל מכוון.
- תוצר-לוואי של הסריקה הוא **זיהוי מעגל**: אם לא קיים מיון חוקי, יש בגרף מעגל (קשת back ב-DFS, או צמתים שנותרו ב-Kahn).
- המיון לרוב **אינו יחיד** — לאותו DAG יכולים להיות מיונים טופולוגיים חוקיים רבים.

## איך זה עובד

**שיטה 1 — DFS לפי זמני סיום.**

1. הרץ [[Depth-First Search (DFS)|חיפוש לעומק (DFS)]] על הגרף.
2. בכל פעם שצומת `u` **מסיים** (הופך שחור), הכנס אותו לראש רשימה `L`.
3. בסיום, `L` הוא מיון טופולוגי (צמתים בסדר זמן-סיום `f[]` **יורד**).

**שיטה 2 — אלגוריתם Kahn (לפי דרגות-כניסה).**

1. חשב את **דרגת-הכניסה** של כל צומת; הכנס לתור את כל הצמתים בעלי דרגת-כניסה 0.
2. הוצא חוזר ונשנה צומת `u` מהתור, צרף אותו לפלט, ו**הורד ב-1** את דרגת-הכניסה של כל שכן `v`; אם `v` הגיע ל-0, הכנס אותו לתור.
3. אם כל `|V|` הצמתים יצאו לפלט → מיון חוקי. אם חלקם לא הגיעו לדרגת-כניסה 0 → בגרף יש **מעגל**.

## פסאודו-קוד

```text
TOPOLOGICAL-SORT-DFS(G):
    DFS(G)
    כאשר צומת u מסיים (הופך שחור):
        הכנס את u לראש הרשימה L
    return L                         # סדר זמן-סיום f[] יורד

TOPOLOGICAL-SORT-KAHN(G):
    חשב in-degree[v] לכל v
    Q ← כל v עם in-degree[v] = 0
    while Q ≠ ∅:
        u ← DEQUEUE(Q); צרף את u לפלט
        for each (u, v) ∈ E:
            in-degree[v] -= 1
            if in-degree[v] = 0: ENQUEUE(Q, v)
    if בפלט פחות מ-|V| צמתים: return "CYCLE"   # לא DAG
```

## דוגמה

DAG עם הקשתות `A → B`, `A → C`, `B → D`, `C → D`. הרצת Kahn:

| צעד | תור דרגת-כניסה 0 | הוצא | הפלט עד כה |
|---|---|---|---|
| אתחול | {A} | — | () |
| 1 | {B, C} | A | (A) |
| 2 | {C} | B | (A, B) |
| 3 | {D} | C | (A, B, C) |
| 4 | {} | D | (A, B, C, D) |

מיון חוקי: `A, B, C, D`. (גם `A, C, B, D` חוקי — המיון כאן **אינו יחיד**, כי אין מסלול בין `B` ל-`C`.)

> [!info] מתי המיון יחיד?
> מיון טופולוגי **יחיד** ⟺ קיים מסלול מכוון (שרשרת המילטונית) ש**עובר בכל הצמתים לפי אותו סדר** — כלומר קיימת קשת בין כל שני צמתים עוקבים במיון. אם לשני צמתים אין מסלול ביניהם, ניתן להחליף ביניהם ולקבל מיון חוקי נוסף.

## איך זה מופיע במבחן

מיון טופולוגי מופיע גם כטענת **הוכח/הפרך** (שאלה 1) וגם כסעיף **רב-ברירה** — לרוב על קיום, יחידות, או השוואת מיון לקסיקוגרפי עולה מול יורד.

- **קיום ושיטה.** *(2023 סמ"ב מועד ב, שאלה 2)* — נתון פסאודו-קוד של Kahn: הרץ אותו, תן גרף שמחזיר FALSE (= יש מעגל), וזהה שהוא מחשב מיון טופולוגי. *(2024 סמ"ב מועד מיוחד, שאלה 1א)* — קיום שורש בגרף מכוון ⟹ קיים מיון טופולוגי.
- **נגישות ויחידות.** *(2022 סמ"ב מועד ב, שאלה 1א / 2024 סמ"ב מבחן לדוגמה, שאלה 1א — נכון)* — כל מיון טופולוגי חוקי ניתן להתקבל מ-`TOPOLOGICAL_SORT`. *(2025 קיץ מועד א, שאלה 3ג — רב-ברירה)* — "שני צמתים ללא מסלול ביניהם ⟺ שני מיונים שונים" ו-"מסלול דרך כל הצמתים ⟹ מיון יחיד". *(2025 קיץ מועד ב, שאלה 1א)* — אם `u` לפני `v` במיון כלשהו, האם בהכרח קיים מסלול `u → v`? *(לא — סדר ≠ קשת ישירה.)*
- **וריאנטים לקסיקוגרפיים וגרף-העל.** *(2025 סמ"ב מועד א, שאלה 3ד — רב-ברירה)* — מיון לקסיקוגרפי עולה מול יורד של DAG משימות: אילו מיקומים משותפים. *(2024 סמ"ב מועד א, שאלה 1ב — לא נכון)* — `|E(G)| = |E(Gˢᶜᶜ)|` **אינו** גורר שלגרף-העל מיון טופולוגי יחיד.

> [!tip] כלל היחידות ששווה לזכור
> ל-DAG יש מיון טופולוגי **יחיד** **⟺ קיים מסלול מכוון העובר בכל `|V|` הצמתים לפי סדר המיון** (שרשרת המילטונית). כדי להריץ את המיון, בנה את זמני-הסיום של [[Depth-First Search (DFS)|חיפוש לעומק (DFS)]] והפוך אותם; בשאלות מעגל, זכור שהמיון מוגדר **רק** על DAG — גרף-העל שמייצרים [[Strongly Connected Components (SCC)|רכיבים קשירים חזק (SCC)]] הוא המקום הקנוני שבו מיון טופולוגי חל.
